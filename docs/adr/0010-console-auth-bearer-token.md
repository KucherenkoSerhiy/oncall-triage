# 0010. Console authentication v1 is a bearer token

- Status: accepted
- Date: 2026-09-07
- Design reference: docs/DESIGN.md, decision D10

## Context

The console must not be open to the world, but Cognito or Entra ID SSO adds a service, a hosted UI and a login flow the demo does not need yet.

## Decision

A random bearer token (generated by Terraform, stored in SSM) is entered once in the browser and kept in localStorage; the console API checks it on every request. The webhook write paths use HMAC signatures instead and are unaffected.

## Consequences

Twenty lines of code, no new service; the token is rotated by re-applying Terraform; SSO is a documented v2 with no change to the API contract.
