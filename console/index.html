Nordwind Bank alert triage

The on-call console of a portfolio project. Alerts from a simulated bank estate on AWS, Azure and Kubernetes are triaged by an LLM agent into page, monitor or ack verdicts, which land on this page.

  • Source and architecture the README shows the system in one picture
  • Recorded runs the weekly job that breaks the estate on purpose and lets the agent triage it
  • Design notes and decisions ADRs, specs, runbooks, cost

The live view needs a bearer token. It is kept only in this browser's local storage.
